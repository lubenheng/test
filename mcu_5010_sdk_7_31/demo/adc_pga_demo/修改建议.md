# MCPWM触发ADC采样 → TIMER触发ADC采样 修改建议

## 一、概述

当前 `adc_mcpwm_trig_demo` 使用 **MCPWM** 作为 ADC 采样触发源，需要将其改为 **通用TIMER（TIMER13-16）** 触发。SDK 已内置支持 TIMER 触发，改动集中在触发源选择和外设配置替换。

---

## 二、触发源宏定义

SDK 在 `system/peripherals/ADC/ADC_Type.h`（第64-72行）定义了所有触发源：

| 宏常量 | 值 | 说明 |
|--------|-----|------|
| `ADC_GrpTrig_MCPWM_TRIG0` | 0 | MCPWM触发源0 |
| `ADC_GrpTrig_MCPWM_TRIG1` | 1 | MCPWM触发源1 |
| `ADC_GrpTrig_MCPWM_TRIG2` | 2 | MCPWM触发源2 |
| `ADC_GrpTrig_MCPWM_TRIG3` | 3 | MCPWM触发源3 |
| `ADC_GrpTrig_TMR13_TRIG` | 4 | **TIMER13触发** |
| `ADC_GrpTrig_TMR14_TRIG` | 5 | **TIMER14触发** |
| `ADC_GrpTrig_TMR15_TRIG` | 6 | **TIMER15触发** |
| `ADC_GrpTrig_TMR16_TRIG` | 7 | **TIMER16触发** |
| `ADC_GrpTrig_SW_TRIG` | 8 | 软件触发 |

```c
/**
 * @brief  初始化PB2为推挽输出，用于观察TIMER触发频率
 *         PB2输出方波频率 = TIMER触发频率 / 2
 * @param  none
 * @return none
 */
void pb2_gpio_init(void)
{
    gpio_settings_config_t setting_cfg;

    /* PB2 推挽输出，默认低电平 */
    setting_cfg.gpio_port     = GPIO_B;
    setting_cfg.gpio_pin      = GPIO_PIN_2;
    setting_cfg.gpio_alt      = GPIO_ALT_FUNC_0;   /* GPIO功能 */
    setting_cfg.gpio_dir      = GPIO_DIR_OUTPUT;
    setting_cfg.pull_cfg      = GPIO_PULL_DISABLE;
    setting_cfg.gpio_strength = GPIO_STRENGTH_MODE_1;
    setting_cfg.gpio_interrupt_cfg_info.int_handle = NULL;
    gpio_init(&setting_cfg);

    /* 初始输出低电平 */
    gpio_output_set(GPIO_B, GPIO_PIN_2, GPIO_LOW_LEVEL);
}

/**
 * @brief  TIMER初始化 —— 使用TIMER13产生周期性ADC触发信号
 *         通过TIMER13的CH0比较匹配事件产生ADC_GrpTrig_TMR13_TRIG，
 *         同时使能TIMER13中断用于PB2翻转验证
 * @param  none
 * @return none
 */
void TIMER_ADC_Init(void)
{
    /* 使能TIMER时钟（具体函数名以clock.h为准） */
    timer_clk_enable();

    /* 清零TIMER13全部配置 */
    Timer_drv_Setting_Clean_all(TIMER13);

    /*
     * 设置时钟分频系数
     * 例如 DIV_8: 48MHz / 8 = 6MHz 计数频率
     */
    TIMER_Set_CLKDIV(TIMER13, TIMER_DIV_8);

    /* 选择内部时钟源 */
    Timer_Set_ClkSrc(TIMER13, TIMERx_INNERCLK);

    /* 自动重载模式（周期性触发） */
    Timer_Set_RLMode(TIMER13, TIMERx_AUTO_RELOAD);

    /* 向上计数 */
    Timer_Set_CNTR_Dir(TIMER13, TIMERx_CNTR_UP);

    /* 边沿对齐模式 */
    Timer_Set_Center_Mode(TIMER13, TIMERx_EDGE_MODE);

    /* 禁用影子寄存器（立即更新） */
    Timer_Set_Shadow(TIMER13, TIMERx_SHADOW_REG_DIS);

    /*
     * 设置CH0为PWM输出模式
     * 产生比较匹配事件，通过EVTSRC路由到ADC触发
     */
    TIMER_Set_CH_Mode(TIMER13, TIMERx_CH0, TIMERx_MODE_PWM);

    /*
     * 设置周期值 TH (决定ADC采样频率)
     * 采样频率 = (MCU_CLK / CKDIV) / (TH+1)
     * 例如: 6MHz / 6000 = 1kHz 采样率
     */
    Timer_Set_ThVal(TIMER13, 6000 - 1);

    /*
     * 设置CH0比较值（触发点相位，在TH范围内）
     * 例如 1 表示计数器到1时触发，几乎在周期开始触发
     */
    Timer_Set_Comp0_Val(TIMER13, 1);

    /*
     * ★ 关键配置：设置事件源
     * TIMER13_CH0_CAPCOM_EVT → ADC触发信号
     */
    Timer_Set_EvtSrc(TIMER13, TIMER13_CH0_CAPCOM_EVT);

    /*
     * 使能TIMER13 CH0中断（用于PB2翻转验证定时精度）
     */
    Timer_IRQ_Enable(TIMER13, TIMERx_IRQ_CH0);

    /* NVIC配置TIMER13中断 */
    NVIC_SetPriority(TIM13_IRQn, 1);
    NVIC_ClearPendingIRQ(TIM13_IRQn);
    NVIC_EnableIRQ(TIM13_IRQn);

    /* 更新寄存器 */
    Timer_Reg_Update(TIMER13);

    /* 启动TIMER13 */
    Timer_Enable(TIMER13);
}
```

### 4.4 `isr.c` 修改 —— TIM13中断服务函数中翻转PB2

在 `isr.c` 中修改 `TIM13_IRQHandler()`（原文件约265行处），实现PB2翻转：

```c
/****************************************************************************
 ** \brief	TIM13_IRQHandler
 **
 ** \param [in]  none   
 ** \return none
 ** \note 	number 13
 **   在CH0比较匹配中断中翻转PB2电平，
 **   用示波器测量PB2方波周期可验证TIMER定时精度。
 **   PB2方波频率 = ADC触发频率 / 2
 ****************************************************************************/
void TIM13_IRQHandler(void)
{
    static uint8_t pb2_level = 0;

    /* 读取并清除TIMER13中断标志 */
    uint8_t irq_status = Timer_drv_IRQ_Status_Get(TIMER13);

    /* CH0比较匹配中断 */
    if (irq_status & (1 << TIMERx_IRQ_CH0))
    {
        /* 翻转PB2电平 */
        pb2_level = !pb2_level;
        if (pb2_level)
        {
            gpio_output_set(GPIO_B, GPIO_PIN_2, GPIO_HIGH_LEVEL);
        }
        else
        {
            gpio_output_set(GPIO_B, GPIO_PIN_2, GPIO_LOW_LEVEL);
        }
    }
}
```

原有的 `MCPWM0_IRQHandler` 和 `MCPWM1_IRQHandler` 已被注释，TIMER方案无需这些中断，可保留不动或清理。

## 五、多TIMER独立触发方案（高级用法）

如果原 MCPWM 方案中4个Group需要**不同的触发时机**，可使用4个不同的TIMER分别触发：

```c
/* Group0 → TIMER13触发 */
ADC_SetGrpTrigSource(ADC_Sample_Group_0, ADC_GrpTrig_TMR13_TRIG);

/* Group1 → TIMER14触发 */
ADC_SetGrpTrigSource(ADC_Sample_Group_1, ADC_GrpTrig_TMR14_TRIG);

/* Group2 → TIMER15触发 */
ADC_SetGrpTrigSource(ADC_Sample_Group_2, ADC_GrpTrig_TMR15_TRIG);

/* Group3 → TIMER16触发 */
ADC_SetGrpTrigSource(ADC_Sample_Group_3, ADC_GrpTrig_TMR16_TRIG);
```

## 六、采样频率计算

```
ADC采样频率 = TIMER计数频率 / (TH + 1)
           = (MCU_CLK / CKDIV分频系数) / (TH + 1)
```

### 计算示例

| MCU_CLK | CKDIV | 计数频率 | TH值 | ADC采样频率 |
|---------|-------|---------|------|------------|
| 48MHz | DIV_1 (÷1) | 48MHz | 6000-1=5999 | 8kHz |
| 48MHz | DIV_8 (÷8) | 6MHz | 6000-1=5999 | 1kHz |
| 48MHz | DIV_8 (÷8) | 6MHz | 600-1=599 | 10kHz |
| 48MHz | DIV_16 (÷16) | 3MHz | 3000-1=2999 | 1kHz |
| 48MHz | DIV_1 (÷1) | 48MHz | 48000-1=47999 | 1kHz |

## 七、MCPWM vs TIMER 方案对比

| 比较项目 | MCPWM方案 | TIMER方案 |
|----------|----------|-----------|
| **触发源** | `ADC_GrpTrig_MCPWM_TRIGx` (0-3) | `ADC_GrpTrig_TMR13_TRIG` 等 (4-7) |
| **使用外设** | MCPWM0（6通道PWM模块） | TIMER13-16（通用定时器） |
| **配置复杂度** | 高（需配置GPIO、6路PWM、触发计数寄存器） | 低（只需配置定时器周期和事件源） |
| **GPIO占用** | **6个**PWM输出引脚（PTA6-PTA11） | **0个**（纯内部触发，无IO占用） |
| **独立触发点数** | 4个（TIG_TMR0-3，可设不同相移） | 1-4个（1个TIMER→1个触发，4个TIMER→4个触发） |
| **触发相位设置** | 通过MCPWM触发计数寄存器 | 通过TIMER比较值寄存器 |
| **是否需要中断** | 需要MCPWM0_IRQn | 仅验证时需要TIMER中断，正常采集不需要 |
| **代码行数** | ~222行 | ~150行（减少约32%） |
| **适用场景** | 电机控制等需要PWM同步采样的场景 | 通用周期性ADC采样 |
| **功耗** | MCPWM模块持续运行 | TIMER模块持续运行（功耗更低） |

### 8.1 TIMER驱动API（`TIM.h` / `TIM.c`）

| 函数 | 功能 |
|------|------|

| `Timer_Set_CNTR_Dir(TIMx, Dir)` | 计数方向（向上/向下） |
| `Timer_Set_Center_Mode(TIMx, Mode)` | 对齐模式（边沿/对称） |
| `Timer_Set_Shadow(TIMx, En)` | 影子寄存器使能 |
