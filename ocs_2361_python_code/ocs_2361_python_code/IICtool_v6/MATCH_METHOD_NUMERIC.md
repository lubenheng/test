# 数值匹配方法说明（MATCH_METHOD_NUMERIC.md）

说明：本方法仅基于数值列进行匹配，不使用名称或字符串相似度。用于把 `2361_配置寄存器_V0.4.xlsx` 中匹配的列 D/E/F/G 覆盖到目标文件中。

目标文件（默认）： MTP_预定位_IF_FOC150K五段式SP备份20260424.xlsx
源文件（默认）： 2361_配置寄存器_V0.4.xlsx

匹配规则：

- 目标文件：使用 J 列（寄存器 ADDR，列号 10）和 K 列（寄存器 index，列号 11）作为匹配键。
- 源文件：使用 B 列（ADDR，列号 2）和 C 列（INDEX，列号 3）作为匹配键。
- 两边必须都能成功解析为整数（支持十进制、十六进制前缀 `0x`、或前导数字字符串）。
- 匹配条件：目标 (J, K) 与 源 (B, C) 的整数值完全相等。

覆盖行为：

- 当找到匹配时，复制源行的 D/E/F/G（列号 4..7）到目标对应行的 D/E/F/G（列号 4..7），覆盖原值（保留单元格格式但替换 cell.value）。
- 如果源中存在重复的 (ADDR, INDEX) 键，脚本只保留第一个遇到的来源行并记录重复信息（不会覆盖为后续重复）。
- 若目标行的 J/K 任一无法解析为整数，则跳过该行（不改动）。
- 若没有找到匹配键，则目标行保持不变（并在报告中标记为未找到）。

输出：

- 生成一个新的 XLSX 文件，文件名由 `--out` 指定；若未指定，默认使用目标文件名的 `.updated.xlsx` 后缀。
- 可选生成 CSV 报告（`--report`），包含每个目标行的匹配状态（updated / not_found / no_key）与源行号。

脚本：

- 位于仓库： `apply_numeric_overlay.py`。
- 运行示例：

  c:/.../.venv/Scripts/python.exe apply_numeric_overlay.py --target MTP_预定位_IF_FOC150K五段式SP备份20260424.xlsx --source 2361_配置寄存器_V0.4.xlsx --out result.xlsx --report overlay_report.csv

注意事项：

- 请确保两个文件在运行时未被 Excel 占用（否则保存可能失败）。
- 匹配以整数为准，若源/目标列中是带注释的字符串（如 "4 #sym:..."），脚本会提取前导数字作为匹配值。
