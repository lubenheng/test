# IIC Tool v6 使用说明

本文档说明 IIC Tool v6 的基本使用流程，包括软件启动、I2C 初始化、IIC 寄存器模式、MTP 测设模式、批量 Excel 操作、日志导出和常见现象。

## 1. 使用前准备

### 1.1 硬件连接

1. 将 USB 转 IIC 工具连接到电脑。
2. 将工具的 IIC 线连接到目标板对应接口。
3. 给目标板上电，并确认目标芯片处于可通信状态。
4. 在 Windows 设备管理器中确认 USB 工具对应的串口号，例如 `COM6`。

### 1.2 文件准备

软件目录中需要保留以下关键文件：

- `IICtool.py`：主程序。
- `i2c_comm.py`、`iic_ops.py`、`mtp_ops.py`、`mtp_batch_ops.py`：通信和业务逻辑文件。
- `USB2UARTSPIIICDLL.dll`：USB 转 IIC 工具 DLL。
- `i2c_config.json`：默认配置文件。

`i2c_config.json` 示例：

```json
{
    "port": "COM6",
    "slave_addr": "0x52",
    "iic_speed": "100k"
}
```

说明：

- `port`：默认串口号，软件启动后会显示在顶部 `Port` 输入框。
- `slave_addr`：IIC 从机地址，当前软件从配置文件读取，不在界面中单独填写。
- `iic_speed`：默认 IIC 速率，支持 `1k`、`5k`、`10k`、`20k`、`50k`、`80k`、`100k`、`200k`、`400k`。

如果串口号或从机地址变化，先修改 `i2c_config.json`，再重新启动软件。

## 2. 软件启动

### 2.1 运行方式

如果使用 Python 源码运行，在软件目录执行：

```powershell
python IICtool.py
```

如果已经打包成 exe，直接双击 exe 文件运行。

### 2.2 启动后的界面

软件标题为 `IIC Tool v6`，主界面包含：

- 顶部连接区：`Port`、`IIC速率`、`初始化I2C`、`关闭串口`、`触发SCK`、状态显示。
- `IIC操作寄存器` 页：普通寄存器读写、批量读写、读回导出。
- `MTP测设模式` 页：MTP 使能、读、写、擦除、批量烧录和导出。
- 底部 `操作日志` 区：显示每一步操作结果。
- 底部按钮：`导出日志`、`主动拉高/恢复死锁`。

刚启动时，右上角状态显示：

```text
状态: 未初始化
```

## 3. 初始化 I2C

### 3.1 初始化步骤

1. 在顶部 `Port` 中填写实际串口号，例如 `COM6`。
2. 在 `IIC速率` 下拉框选择通信速率，常用默认值为 `100k`。
3. 点击 `初始化I2C`。

### 3.2 初始化成功现象

正常情况下：

- 状态栏变为：

```text
状态: 已初始化 (原始IIC模式)
```

- `初始化I2C` 按钮变灰，不可重复点击。
- `Port` 输入框变灰，防止运行中修改串口。
- `IIC速率` 下拉框变灰，表示当前速率已应用。
- `关闭串口` 按钮可点击。
- 日志区出现类似信息：

```text
→ 发送 I2C 初始化命令: 0300080800000000
← 初始化响应: ...
DLL已就绪: ...
→ 已应用 IIC 速率: 100k
```

### 3.3 初始化失败现象

如果初始化失败，软件会弹窗提示 `初始化失败`，状态栏会显示失败原因，日志区会出现 `!!` 开头的错误信息。

常见原因：

- 串口号填写错误。
- 串口被其他软件占用。
- USB 工具未插好或驱动异常。
- `USB2UARTSPIIICDLL.dll` 缺失。
- `i2c_config.json` 中 `slave_addr` 地址错误。
- 目标板未上电或 IIC 线连接异常。

处理方式：

1. 检查设备管理器中的真实 COM 口。
2. 关闭其他占用串口的软件。
3. 检查 DLL 是否在软件目录。
4. 检查目标板供电和 IIC 线序。
5. 修改 `i2c_config.json` 后重启软件再初始化。

### 3.4 关闭串口

点击 `关闭串口` 后：

- 状态栏显示：

```text
状态: 串口已关闭
```

- `初始化I2C` 恢复可点击。
- `Port` 和 `IIC速率` 恢复可修改。

更换目标板、修改速率或修改配置文件后，建议先关闭串口，再重新初始化。

## 4. 触发 SCK

`触发SCK` 用于通过 PWM 方式输出一段 SCK 脉冲，常用于特殊状态恢复或配合外部时序调试。

使用方式：

1. 确认 `Port` 填写正确。
2. 点击顶部 `触发SCK`。

正常日志现象：

```text
SPI_SCK_DIRECT | 开始发送 30 脉冲，总时长 500 µs (使用 PWM)
→ 使用参数: prescaler=0, period=..., pulse=..., pulse_num=1
→ PWM 已启动: ...
SPI_SCK_DIRECT | 发送完成: 30 脉冲
```

失败时日志会显示：

```text
!! SPI_SCK_DIRECT 失败: ...
```

初始化 I2C 后，`触发SCK` 按钮会被禁用。

## 5. IIC 操作寄存器模式

进入 `IIC操作寄存器` 页可进行普通寄存器读写。

### 5.1 参数含义

- `ADDR (0~31)`：寄存器地址，十进制输入，范围 `0` 到 `31`。
- `INDEX (0~63)`：索引，十进制输入，范围 `0` 到 `63`。
- `写入数据(HEX)`：4 字节十六进制数据。

写入数据支持以下形式：

```text
AA BB CC DD
AABBCCDD
0xAABBCCDD
```

如果输入不足 4 字节，软件会在高位补 `00`。例如输入 `12 34`，按 `00 00 12 34` 处理。

### 5.2 单独写

操作步骤：

1. 填写 `ADDR`。
2. 填写 `INDEX`。
3. 填写 `写入数据(HEX)`。
4. 点击 `单独写`。

正常日志现象：

```text
WRITE | addr=19, index=0 | data=00 00 00 00
```

失败时会弹窗 `错误`，常见为地址越界、索引越界、HEX 格式错误或未初始化。

### 5.3 单独读

操作步骤：

1. 填写 `ADDR`。
2. 填写 `INDEX`。
3. 点击 `单独读`。

正常日志现象：

```text
READ | addr=19, index=0 | rx=AA BB CC DD
```

如果没有有效返回，日志显示：

```text
READ | 无有效返回
```

### 5.4 写后读

`写后读` 会先写入 4 字节数据，再立即读取同一个 `ADDR/INDEX`。

操作步骤：

1. 填写 `ADDR`、`INDEX`、`写入数据(HEX)`。
2. 点击 `写后读`。

正常日志现象：

```text
WRITE | addr=19, index=0 | data=12 34 56 78
READ | addr=19, index=0 | rx=12 34 56 78
```

该功能适合确认寄存器是否写入成功。

### 5.5 快速行操作

页面中间有 5 行快速操作区，每行包含：

- `ADDR`
- `INDEX`
- `[31:24]`
- `[23:16]`
- `[15:8]`
- `[7:0]`
- `写`
- `读`
- `写后读`

使用方式：

1. 在某一行填写地址、索引和 4 个字节。
2. 点击该行的 `写`、`读` 或 `写后读`。

正常现象：

- `写`：日志显示 `WRITE | ...`。
- `读`：日志显示 `READ | ...` 和 `读回: ...`。
- `写后读`：日志显示写入、读回，并显示 `快速行X 写后读回: ...`。

快速行适合反复调试多个固定寄存器。

## 6. IIC 批量 Excel 操作

### 6.1 生成模板

点击 `生成模板`，选择保存位置后，会生成一个 Excel 文件，默认文件名类似：

```text
批量操作模板_YYYYMMDD_HHMMSS.xlsx
```

模板字段：

| 列名 | 含义 |
| --- | --- |
| `READ/WRITE/WRITETHENREAD` | 操作类型 |
| `ADDR` | 地址，范围 0~31 |
| `INDEX` | 索引，范围 0~63 |
| `[31:24]` | 写入或读回的最高字节 |
| `[23:16]` | 第 2 字节 |
| `[15:8]` | 第 3 字节 |
| `[7:0]` | 最低字节 |

模板中 `START` 和 `END` 之间为有效操作区域。

支持的操作类型：

- `WRITE`：只写入。
- `READ`：只读取。
- `WRITETHENREAD`：写入后读回并校验。

注释规则：

- 空行会跳过。
- 以 `#`、`//`、`注` 开头的行会跳过。

### 6.2 批量执行

操作步骤：

1. 点击 `生成模板`。
2. 在 Excel 的 `START` 和 `END` 之间填写操作行。
3. 保存 Excel。
4. 回到软件，点击 `批量执行`。
5. 选择刚才填写好的 Excel。

执行顺序：

1. 先执行所有 `WRITE` 和 `WRITETHENREAD` 的写入。
2. 再执行所有 `READ`。
3. 最后执行所有 `WRITETHENREAD` 的读回校验。

成功现象：

```text
=== 批量写入与校验完成：共执行 X 条，校验全部通过！ ===
```

弹窗显示：

```text
共处理 X 条命令
全部校验通过！
详情见日志
```

校验失败现象：

- 软件弹窗 `批量校验失败`。
- 日志中显示预期值和实际读回值，例如：

```text
!! 第 5 行(ADDR=2, INDEX=10)校验失败! 预期:12 34 56 78, 实际:12 34 56 00
```

### 6.3 批量读回并覆盖

`批量读回并覆盖` 会读取 Excel 中每一行的 `ADDR/INDEX`，并把读回值写回 Excel 的 `[31:24]` 到 `[7:0]` 列。

操作步骤：

1. 点击 `批量读回并覆盖`。
2. 选择 Excel 文件。
3. 等待进度窗口完成。
4. 选择保存为新文件，或取消保存路径后覆盖原文件。

成功现象：

```text
读回并更新完成
成功 X/Y 条
```

该功能适合把芯片当前寄存器值读回形成记录。

### 6.4 读数据并导出

该功能按界面填写的地址和索引范围批量读取，并生成 Excel。

界面字段：

- `导出地址(0-31)`：可输入单个地址、逗号分隔列表或范围。
- `导出索引范围(0-63)`：可输入单个索引、逗号分隔列表或范围。

示例：

```text
导出地址: 19
导出索引范围: 0-10
```

```text
导出地址: 1,2,3
导出索引范围: 0,5,8-12
```

操作步骤：

1. 填写导出地址和索引范围。
2. 点击 `读数据并导出`。
3. 选择保存位置。

成功现象：

```text
读数据并导出完成: 总计 X 条, 成功 Y 条
```

## 7. MTP 测设模式

进入 `MTP测设模式` 页可进行 MTP 字节读写、擦除、批量烧录和导出。

### 7.1 MTP 地址说明

MTP 地址范围为 `0~511`，按字节寻址。

界面字段：

- `ADDR(MTP Byte, 0~511)`：MTP 字节地址。
- `Byte Data(HEX)`：单字节写入数据，范围 `00~FF`。
- `操作扇区(0~15)`：MTP 扇区号。
- `写入统一数据(Hex)`：向整个扇区写入的统一字节值。

扇区关系：

```text
每个扇区 32 字节
扇区 0: 地址 0~31
扇区 1: 地址 32~63
...
扇区 15: 地址 480~511
```

### 7.2 Open MTP EN

执行 MTP 烧录或擦除前，需要先开启 MTP 使能。

操作步骤：

1. 确认已经初始化 I2C。
2. 点击 `Open MTP EN`。

软件实际会连续下发 3 次寄存器写入，用于解锁并打开 MTP EN：

| 顺序 | ADDR | INDEX | 写入值 |
| --- | --- | --- | --- |
| 1 | `25` | `4` | `5A 5A 5A 5A` |
| 2 | `20` | `15` | `5A 5A 5A 5A` |
| 3 | `30` | `0` | `5A 5A 5A 5A` |

正常日志现象：

```text
WRITE | addr=25, index=4 | data=5A 5A 5A 5A
WRITE | addr=20, index=15 | data=5A 5A 5A 5A
WRITE | addr=30, index=0 | data=5A 5A 5A 5A
MTP: Open MTP EN -> addr=30, index=0, value=0x00000100
```

如果失败，日志显示：

```text
!! Open MTP EN 失败: ...
```

### 7.3 Close MTP EN

MTP 操作完成后，点击 `Close MTP EN` 关闭 MTP 使能。

软件实际会连续下发 2 次寄存器写入，用于关闭 MTP EN：

| 顺序 | ADDR | INDEX | 写入值 |
| --- | --- | --- | --- |
| 1 | `30` | `0` | `A5 A5 00 A5` |
| 2 | `20` | `15` | `A5 A5 00 A5` |

正常日志现象：

```text
WRITE | addr=30, index=0 | data=A5 A5 00 A5
WRITE | addr=20, index=15 | data=A5 A5 00 A5
MTP: Close MTP EN -> addr=30, index=0, value=0x00000000
```

建议在 MTP 烧录、擦除或调试完成后关闭 MTP EN。

### 7.4 Read Byte

读取单个 MTP 字节。

操作步骤：

1. 在 `ADDR(MTP Byte, 0~511)` 填写地址。
2. 点击 `Read Byte`。

正常情况下，日志会显示对应底层读操作的 `READ | ... | rx=...`。

注意：MTP 单字节读回值取读回 4 字节中的最低字节 `[7:0]`。

### 7.5 Program Byte

烧录单个 MTP 字节。

操作步骤：

1. 点击 `Open MTP EN`。
2. 在 `ADDR(MTP Byte, 0~511)` 填写地址。
3. 在 `Byte Data(HEX)` 填写 `00~FF`。
4. 点击 `Program Byte`。

正常日志现象：

```text
MTP: 烧录地址 10 数据 0x5A
```

注意：

- MTP 写入前通常需要先擦除对应扇区或全片。
- 当前软件对单字节烧录会连续下发两次写命令。

### 7.6 Sector Erase

按当前 `ADDR(MTP Byte, 0~511)` 所在扇区执行擦除。

操作步骤：

1. 点击 `Open MTP EN`。
2. 在 `ADDR(MTP Byte, 0~511)` 填写目标地址。
3. 点击 `Sector Erase`。

例如地址 `40` 属于扇区 `1`，会擦除扇区 `1`。

正常日志现象：

```text
MTP: 擦除扇区 1...
已下发 MTP Sector 1 擦除指令
```

### 7.7 Chip Erase

全片擦除 MTP。

操作步骤：

1. 点击 `Open MTP EN`。
2. 点击 `Chip Erase`。

正常日志现象：

```text
MTP: 下发全片擦除指令
已下发 MTP Chip Erase 擦除全片指令
```

注意：该操作会擦除整片 MTP，执行前必须确认目标板和数据状态。

## 8. MTP 批量操作

### 8.1 生成 MTP 模板

点击 `生成MTP模板`，选择保存位置后生成 Excel，默认文件名类似：

```text
MTP批量模板_YYYYMMDD_HHMMSS.xlsx
```

模板字段：

| 列名 | 含义 |
| --- | --- |
| `OPERATION` | 操作类型 |
| `ADDR(基地址)` | MTP 基地址 |
| `INDEX(Word偏移)` | Word 偏移 |
| `[31:24]` | 对应物理地址 `ADDR + INDEX*4 + 3` |
| `[23:16]` | 对应物理地址 `ADDR + INDEX*4 + 2` |
| `[15:8]` | 对应物理地址 `ADDR + INDEX*4 + 1` |
| `[7:0]` | 对应物理地址 `ADDR + INDEX*4 + 0` |
| `物理地址(计算)` | Excel 公式，通常为 `=B列+C列*4` |

支持的操作类型：

- `PROGRAM`：写入 4 个连续字节。
- `READ`：读取 4 个连续字节。
- `ERASE_SECTOR`：擦除物理地址所在扇区。

### 8.2 全片擦写+校验

`全片擦写+校验` 从 MTP Excel 中读取 `PROGRAM` 行，计算 CRC，执行两遍烧录，然后读回比对。

推荐步骤：

1. 点击 `生成MTP模板`。
2. 在 Excel 中填写需要烧录的数据。
3. 回到软件，初始化 I2C。
4. 点击 `Open MTP EN`。
5. 点击 `Chip Erase` 或按需求执行 `Sector Erase`。
6. 点击 `全片擦写+校验`。
7. 选择填写好的 Excel 文件。
8. 软件会先弹窗显示计算出的 CRC。
9. 确认已经手动完成 `擦除 + Open MTP EN` 后，点击 `是` 开始烧录。

烧录期间现象：

- 弹出 `烧录中...` 进度窗口。
- 日志显示：

```text
*** 开始第 1 遍全片烧录 ...
*** 开始第 2 遍全片烧录 ...
```

烧录后现象：

- 弹出 `读回并比对中...` 进度窗口。
- 日志逐项显示校验结果。

校验通过现象：

```text
=== MTP 烧录校验全部通过 ===
=== MTP 物理全片 CRC 烧写完成 ===
```

弹窗显示：

```text
所有写入字节已验证通过。
最终 CRC 为 0xXXXXXXXX。
```

校验失败现象：

```text
!! 校验失败: addr=..., 期望=0x.., 读回=0x..
=== MTP 烧录校验发现 X 处不一致 ===
```

弹窗会显示前若干条不一致地址，完整信息看日志区。

### 8.3 读出 MTP 并导出

`读出MTP并导出` 会读取 MTP 地址 `4~315` 的数据，并额外读取 CRC 区域，导出为 MTP 模板格式。

操作步骤：

1. 初始化 I2C。
2. 根据芯片状态需要，点击 `Open MTP EN`。
3. 点击 `读出MTP并导出`。
4. 选择保存位置。
5. 等待进度窗口完成。

成功现象：

```text
MTP读出并导出成功: 总计 X 条, 成功 Y 条
```

导出的 Excel 中还会附带一行 `CALCULATED(本次数据算得的新CRC)`，用于对比本次读出数据计算得到的新 CRC。

### 8.4 写本扇区(不擦除)

该功能向指定扇区的 32 个字节全部写入同一个字节值，不执行擦除。

操作步骤：

1. 初始化 I2C。
2. 点击 `Open MTP EN`。
3. 根据需要先执行 `Sector Erase` 或 `Chip Erase`。
4. 在 `操作扇区(0~15)` 输入扇区号。
5. 在 `写入统一数据(Hex)` 输入 `00~FF`。
6. 点击 `写本扇区(不擦除)`。
7. 软件弹窗确认后点击 `是`。

成功现象：

```text
开始向扇区 X (地址 A~B) 统一写入数据 0xYY...
=== 扇区 X 批量写入完成 ===
```

弹窗显示：

```text
扇区 X 统一烧写完成。
```

### 8.5 读本扇区并导出

该功能读取指定扇区 32 字节，并导出 Excel。

操作步骤：

1. 初始化 I2C。
2. 在 `操作扇区(0~15)` 输入扇区号。
3. 点击 `读本扇区并导出`。
4. 选择保存位置。

成功现象：

```text
开始读取扇区 X 数据 (地址 A~B) ...
```

## 9. 操作日志

所有操作都会在底部 `操作日志` 中显示，格式包含时间戳，例如：

```text
[2026-06-17 14:30:00] WRITE | addr=19, index=0 | data=00 00 00 00
```

常见日志前缀：

- `WRITE`：写寄存器。
- `READ`：读寄存器。
- `MTP`：MTP 相关操作。
- `BUS_RECOVER`：总线恢复。
- `!!`：错误或异常信息。

### 9.1 导出日志

点击 `导出日志` 可将当前日志保存为 Excel。

导出的字段包括：

- 时间
- 操作类型
- 地址
- 索引
- 写入值
- 读取值
- 原始消息

如果当前没有日志，软件会提示 `当前无日志记录可导出`。

## 10. 主动拉高/恢复死锁

当 IIC 读写超时、总线异常或 SDA/SCL 状态异常时，可以点击 `主动拉高/恢复死锁`。

使用前提：

- 必须已经初始化 I2C。

正常日志现象：

```text
→ 手动触发总线恢复（主动拉高/释放SDA、SCL）
BUS_RECOVER | 手动恢复完成
```

如果未初始化就点击，会提示先初始化 I2C。

## 11. 推荐操作流程

### 11.1 普通寄存器调试流程

1. 连接硬件并上电。
2. 确认 `i2c_config.json` 中 `port` 和 `slave_addr` 正确。
3. 启动软件。
4. 选择 IIC 速率。
5. 点击 `初始化I2C`。
6. 进入 `IIC操作寄存器`。
7. 使用 `单独读` 确认通信正常。
8. 使用 `单独写` 或 `写后读` 调试寄存器。
9. 需要批量操作时，先 `生成模板`，填写后执行 `批量执行`。
10. 调试完成后点击 `导出日志` 保存记录。
11. 点击 `关闭串口`。

### 11.2 MTP 单字节烧录流程

1. 连接硬件并上电。
2. 启动软件并 `初始化I2C`。
3. 进入 `MTP测设模式`。
4. 点击 `Open MTP EN`。
5. 根据需要执行 `Sector Erase`。
6. 填写 `ADDR(MTP Byte, 0~511)` 和 `Byte Data(HEX)`。
7. 点击 `Program Byte`。
8. 点击 `Read Byte` 读回确认。
9. 操作完成后点击 `Close MTP EN`。
10. 导出日志。

### 11.3 MTP 批量烧录流程

1. 点击 `生成MTP模板`。
2. 在 Excel 中填写 `PROGRAM` 数据。
3. 确认数据无误后保存 Excel。
4. 初始化 I2C。
5. 点击 `Open MTP EN`。
6. 点击 `Chip Erase` 或按需求擦除扇区。
7. 点击 `全片擦写+校验`。
8. 选择 Excel。
9. 确认 CRC 弹窗后开始烧录。
10. 等待烧录和读回校验完成。
11. 校验通过后点击 `Close MTP EN`。
12. 导出日志和读回文件作为记录。

## 12. 常见问题和处理

### 12.1 提示“请先点击 初始化I2C 按钮”

原因：当前还没有初始化，或已经点击过 `关闭串口`。

处理：检查 Port 和速率后点击 `初始化I2C`。

### 12.2 串口打开失败

常见原因：

- COM 口错误。
- 串口被其他软件占用。
- USB 工具未连接。
- 驱动异常。

处理：

1. 在设备管理器确认 COM 口。
2. 关闭串口助手等占用工具。
3. 重新插拔 USB 工具。
4. 修改 `i2c_config.json` 或界面 `Port` 后重新初始化。

### 12.3 未找到 DLL

错误类似：

```text
未找到 USB2UARTSPIIICDLL.dll，请确认 DLL 路径
```

处理：

- 确认 `USB2UARTSPIIICDLL.dll` 位于软件目录。
- 如果使用 exe，确认 DLL 已被正确打包或放在 exe 同目录。

### 12.4 读回无有效返回

现象：

```text
READ | 无有效返回
```

可能原因：

- 目标板未上电。
- IIC 从机地址错误。
- IIC 线序接反。
- 速率过高。
- 芯片未处于可读状态。

处理：

1. 检查供电和地线。
2. 检查 `i2c_config.json` 的 `slave_addr`。
3. 降低 IIC 速率，例如从 `400k` 改为 `100k` 或 `50k`。
4. 点击 `主动拉高/恢复死锁` 后重试。

### 12.5 批量校验失败

现象：批量执行或 MTP 烧录后提示校验失败。

处理：

1. 查看日志中的预期值和实际值。
2. 确认 Excel 中字节顺序是否填写正确。
3. 确认 MTP 写入前已擦除。
4. 确认已点击 `Open MTP EN`。
5. 降低 IIC 速率后重试。

### 12.6 MTP 写入后读回不一致

常见原因：

- 未擦除直接写入。
- 未打开 MTP EN。
- 写入地址不正确。
- Excel 物理地址计算不符合预期。
- 芯片保护或状态异常。

处理：

1. 先执行 `Open MTP EN`。
2. 对目标扇区执行 `Sector Erase`，或执行 `Chip Erase`。
3. 再执行写入。
4. 使用 `Read Byte` 或 `读本扇区并导出` 检查结果。

## 13. 注意事项

- MTP 擦除和烧录属于破坏性操作，执行前必须确认目标芯片和数据文件正确。
- `Chip Erase` 会擦除全片 MTP。
- `写本扇区(不擦除)` 不会自动擦除，通常需要先擦除后再写。
- `slave_addr` 当前来自 `i2c_config.json`，不是界面输入项。
- 修改 `i2c_config.json` 后建议重启软件。
- 批量 Excel 操作前建议先用 `单独读` 确认通信正常。
- 烧录前建议导出现有 MTP 数据作为备份。
- 出现通信异常时，先尝试 `主动拉高/恢复死锁`，仍失败再关闭串口并重新初始化。
