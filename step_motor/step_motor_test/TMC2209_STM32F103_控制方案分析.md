# TMC2209 步进电机驱动控制方案分析

> **MCU**：STM32F103C8T6（72MHz，LQFP48）
> **驱动芯片**：TMC2209-LA / TMC2209-LA-T（QFN28，5×5mm，0.5mm pitch）
> **控制模式**：STEP/DIR 硬件控制模式（TIM2 硬件 PWM 产生 STEP，GPIO 控制 DIR/ENN/MS1/MS2）
> **数据手册**：`C2150710_步进电机驱动芯片_TMC2209-LA-T_规格书_WJ337769.PDF`（TRINAMIC TMC2209 Datasheet Rev.1.03）
> **约束**：不修改 STM32CubeMX 生成的代码（Core 目录），用户代码放 USER 目录
> **UART**：暂不使用（纯 STEP/DIR 硬件控制，电流由 RSENSE/VREF 模拟设定，PDN_UART 接地启用静止降流）
> **当前进度**：✅ **缓升/缓降启停控制已实现** —— `Motor_Init()` 设置方向/微步/使能后由 `Motor_Start()` 缓升启动到 `MOTOR_MAX_HZ_DEFAULT`(800Hz)；`Motor_Start(hz)` 运行中可变速（ARR 缓升/缓降逼近 target_arr，CCR=ARR>>1 保持 50%）；`Motor_Stop()` 缓降后停机。当前目标 800Hz → 约 30 RPM（1/8 微步）

## ⚠️ 一、注意事项（先读这里）

1. **上电默认电机处于"禁用"状态**：CubeMX 生成的 `MX_GPIO_Init()` 将 ENN(PA0) 初始化为**高电平**，而 TMC2209 的 ENN 为**低有效**，因此上电后功率级关闭、电机自由。**必须由用户代码将 ENN 拉低（PA0=0）后才可驱动电机**。这是一个很好的安全默认值，改代码时不要破坏它。

2. **VCC_IO 供电范围 3.3V~5V**：TMC2209 的 VCC_IO(15) 接 3.3V（与 STM32 同电源即可）。逻辑高电平门槛 = 0.7×VCC_IO ≈ 2.31V（3.3V 时），STM32 的 3.3V 输出满足要求。注意 TMC2209 的 **5VOUT(8) 是内部 5V 稳压器输出，不是电源输入**，勿接 3.3V 或电源。

3. **VM(VS) 供电 4.75~29V，注意电容与浪涌**：绝对最大额定电压 32V（叠加电感负载振铃时不超过 33V）。VS(22,28) 引脚就近放置 **≥47µF 电解电容 + 100nF 陶瓷电容**；电源走线要粗、回路要短，否则电机制动反电动势与快速开关产生振铃尖峰，可能击穿功率管。

4. **电流与散热强相关**：QFN28 封装在 **≥1.4A RMS 持续电流**时对 PCB 散热敏感（需露铜散热焊盘 + 过孔阵列 + 大面积 GND 铜皮）。连续电流设计上限 1.4A RMS，**2.0A RMS 只能按占空比限制（如 1s 开/1s 停）使用**，峰值电流 ≤2.8A。选型时按公式计算 RSENSE 并用电流探头实测校准。

5. **STEP 脉冲必须无抖动（jitter-free）**：TMC2209 内部 MicroPlyer 依据"相邻两个 STEP 脉冲的时间间隔"做 256 细分插值，**STEP 频率抖动会直接导致转速不平滑**。用 TIM2 硬件 PWM 产生 STEP（当前工程已如此配置）是正确做法，不要用软件延时翻转 GPIO 来产生 STEP。

6. **MS1/MS2 决定微步分辨率**：本方案不使用 UART，MS1/MS2 仅用于选择微步分辨率。当前工程 MS1=PA3、MS2=PA4 由 GPIO 驱动，默认全 0 → 1/8 微步；运行时切换微步只需改写这两个引脚（见 3.4 表）。

7. **PDN_UART(14) 直接接地（不使用 UART 的正确接法）**：本方案暂不使用单线 UART，将 PDN_UART 接 **GND**，启用"静止自动降流"（静止时电流自动降到出厂默认 IHOLD，降低发热与功耗）。**不要把它接到 MCU 串口**。若日后启用 UART，再改为 PA9 经 1kΩ、PA10 直连的接法，并写 `GCONF.pdn_disable=1`。

8. **静止自动降流**：PDN_UART 接 GND 即启用（静止延时后自动降到出厂默认 IHOLD，约 53%×IRUN）；接 VCC_IO 则禁用。本方案接 GND 启用，无需配置任何寄存器。

9. **VREF(17) 是电流设定的关键（不使用 UART 时）**：标准外部采样电阻模式下，VREF **开路**（内部上拉到 5VOUT/2 ≈ 2.5V）即满量程电流，也可用电阻分压器细调（0~2.5V 区间线性缩放）。**不要接 GND**（会把电流调到接近 0）。内部采样电阻模式需 OTP 预烧或 UART 设置 `internal_Rsense`，本方案不涉及，默认走外部采样电阻。

10. **STDBY(20) 悬空即可**：内部 100kΩ 下拉，默认正常运行；拉高进入低功耗待机（约 2mW @12V），退出待机后**所有寄存器复位为默认值**，且要求 ENN/VREF 为低。本设计不需要使用。

11. **SPREAD(7) 悬空即可**：内部下拉 → 默认 **StealthChop2 静音模式**；拉高 → SpreadCycle（动态响应更好，适合高速/大电流）。3D 打印等对噪音敏感场景用 StealthChop2。

12. **不得改动 CubeMX 生成代码**：`Core/Src`、`Core/Inc` 下文件（main.c、gpio.c、tim.c、usart.c、dma.c、stm32f1xx_it.c、stm32f1xx_hal_msp.c、system_stm32f1xx.c）由 CubeMX 维护，重新生成会被覆盖。用户代码一律放 `USER/Inc` 与 `USER/Src`（`step_motor_contorl_hardware.c/.h` **已创建并实现第一步**）。main.c 只在 `USER CODE BEGIN/END` 注释块内挂接 `Motor_Init()`（CubeMX 保留这些块）。

13. **USER 源文件已加入 Keil 编译**：Keil 工程 `MDK-ARM/step_motor_test.uvprojx` 的 include 路径已含 `../USER;../USER/Src;../USER/Inc`，USER 组已挂接 `step_motor_contorl_hardware.c` 参与编译。若以后新增 USER 源文件，记得在 Keil 里把它加入 USER 组，否则不会参与编译。

14. **中断注意**：CubeMX 已使能 TIM2/TIM3、USART1、DMA1_Channel4 的中断向量。注意 `HAL_TIM_PWM_Start`（**非 IT 版本**）**不会使能更新中断**，因此第一步匀速转动时 CPU 无中断负担；若后续改用 `HAL_TIM_PWM_Start_IT` 或手动使能更新中断做步数计数，需在 `HAL_TIM_PeriodElapsedCallback()` 中做极短处理。

15. **推荐上电顺序**：① 确认电流已硬件设定（RSENSE 选型 + VREF 开路/分压，见 3.5）→ ② 拉低 ENN 使能功率级 → ③ 启动 TIM2 PWM（开始出 STEP 脉冲）。

### 3.3 STEP/DIR 硬件控制模式（Option 1：Standalone STEP/DIR Driver）

数据手册给出三种工作模式，本设计采用 **Option 1（纯 STEP/DIR 硬件控制，Legacy 模式）**，暂不使用 UART：

- MCU 负责产生 STEP 与 DIR 信号，TMC2209 内部序列器按微步表（1024 点正弦表，对应一个电角度周期=4 个全步）产生两相电流。
- **电流仅通过 VREF 电压（模拟）+ RSENSE 硬件设定**（本方案不使用 UART 的 IRUN/IHOLD 寄存器）；Standalone 模式默认 IRUN=31 满量程、VREF=2.5V（开路），VREF 电压在 0~2.5V 区间线性缩放电流。
- **PDN_UART 接 GND** → 静止自动降流到出厂默认 IHOLD；INDEX 提供位置基准脉冲；DIAG 提供故障信号；ENN 控制使能。
- STEP/DIR 时序要求（数据手册 AC 特性，tCLK=83ns @12MHz）：

| 参数 | 符号 | 最小值 |
|---|---|---|
| STEP 高电平时间 | tSH | max(tFILTSD, tCLK+20) ≈ 100ns |
| STEP 低电平时间 | tSL | 同上 ≈ 100ns |
| DIR → STEP 建立时间 | tDSU | 20ns |
| STEP 有效沿后 DIR 保持时间 | tDSH | 20ns |
| STEP/DIR 毛刺滤波 | tFILTSD | 13~30ns |

- **最大 STEP 频率 fSTEP ≤ ½ fCLK（≈6MHz）**；全步频率上限 fFS ≤ fCLK/512 ≈ 23.4kHz。
- STEP 上升沿（dedge=0）有效；`GCONF.multistep_filt`（默认 1）会对 >750Hz 的 STEP 做软件滤波优化。

### 3.4 微步分辨率配置（MS1/MS2）

| MS2 (PA4) | MS1 (PA3) | 微步设置 | 每个 STEP 脉冲推进 |
|---|---|---|---|
| GND/0 | GND/0 | **1/8 微步**（当前默认） | 1/8 全步（1.8° 电机 → 0.225°） |
| GND/0 | VCC/1 | 1/32 微步（与 TMC2208 不同！） | 1/32 全步 |
| VCC/1 | GND/0 | 1/64 微步（与 TMC2208 不同！） | 1/64 全步 |
| VCC/1 | VCC/1 | 1/16 微步 | 1/16 全步 |

> 注意与 TMC2208 的区别：TMC2208 为 00=1/8、01=1/4、10=1/2、11=1/16；**TMC2209 是 01=1/32、10=1/64**。
>
> 通过 UART 还可把微步进一步设为 fullstep ~ 1/256（`GCONF.mstep_reg_select=1` + `CHOPCONF.MRES`）——本方案暂不使用。本工程 MS1/MS2 由 GPIO 驱动，**可在运行时动态切换 1/8、1/16、1/32、1/64 微步**。

### 3.5 电流设置与计算公式

**Standalone 模式（VREF=2.5V 开路，IRUN=31）运行电流：**

```
IRMS = 325mV / (RSENSE + 20mΩ) × 1/√2
```

**UART 模式（IRUN/IHOLD 电流刻度 CS=0~31）——本方案暂不使用，仅存档备查：**

```
IRMS = (CS+1)/32 × VFS / (RSENSE + 20mΩ) × 1/√2
其中 VFS = 0.325V（CHOPCONF.vsense=0，正文默认 325mV；PDF 参数表标 0.32V 为近似）
         0.18V （CHOPCONF.vsense=1，降低采样电阻功耗）
```

**RSENSE 选择参考表**（VREF=2.5V、IRUN=31、vsense=0）：

| RSENSE | 0.22Ω | 0.18Ω | 0.15Ω | 0.12Ω | 0.10Ω | 0.075Ω |
|---|---|---|---|---|---|---|
| IRMS | 0.96A | 1.15A | 1.35A | 1.64A | 1.92A | 2.4A* |

\* 超过额定，需降低 VREF 分压（或增大 RSENSE）使用。采样电阻需用**低电感型**（1206/0805，0.5W），对称布局、就近芯片。

- 上述 IRUN/IHOLD/IHOLDDELAY 均为 UART 寄存器（本方案不使用）；Standalone 模式下电流固定由 **RSENSE 与 VREF** 决定（等效 IRUN=31）。静止降流由 PDN_UART 接地触发，静止电流为出厂默认 IHOLD（约 53%×IRUN）；如需定制静止电流需 OTP 预烧或日后启用 UART 修改。
- Standalone 模式电流固定为满量程（等效 IRUN=31）；如需降低电流，用 VREF 分压（0~2.5V 线性缩放），并尽量保持 VREF≥1V 以减小模拟噪声影响。
- `TPOWERDOWN`（0x11，默认 20）：检测到静止（stst）到开始降流之间的延时（每档 2^18 时钟），注意最小 2。

### 3.6 单线 UART 配置接口（本方案暂不使用，仅存档备查）

- 通过 PDN_UART 一根线半双工通信，数据帧带 CRC 校验，**自动波特率检测**（9000 ~ fCLK/16）。
- 从机地址由 MS1/MS2 决定：`SLAVEADDR = MS1 + 2×MS2`（0~3）。
- 写访问帧（8 字节，每个字节 LSB 先发，数据字高字节先发）：

```
Byte0 = 0x05                       同步头(sync)
Byte1 = SLAVEADDR (0x00~0x03)       从机地址
Byte2 = 0x80 | 寄存器地址           写标志
Byte3..6 = 32bit 数据 (MSB→LSB)
Byte7 = CRC8 (多项式 x^8+x^2+x+1=0x07, 初值 0)
```

- 读访问帧：Byte2 = 寄存器地址（无 0x80），数据字节填 0；TMC2209 应答：

```
[0x05][0xFF][寄存器地址][32bit 数据 MSB先][CRC8]
```

- 相邻两字节起始位间隔 >63 位时间 → 通信复位，需空闲 ≥12 位时间后重发；错误帧同理。
- 每条被接受的写帧会使 IFCNT(0x02) 计数 +1，可用来校验通信是否丢帧。

### 3.7 电气参数与保护（节选）

| 参数 | 值 |
|---|---|
| 供电电压 VVS（内部稳压器） | 5.5 ~ 29V |
| 供电电压 VVS（稳压器直通 5V 模式） | 4.7 ~ 5.4V |
| VCC_IO | 3.0 ~ 5.25V（待机 1.5V） |
| 逻辑输入高/低电平 | 0.7×VCC_IO / 0.3×VCC_IO |
| 内部下拉电阻 | 132~200kΩ（STDBY 80~120kΩ） |
| 结温 TJ | -40 ~ +125°C（绝对最大 150°C） |
| ESD（应用 HBM） | 4kV |
| 待机功耗 | ≈2mW @12V |

保护功能：过温关断（OT 由 **OTTRIM 可配**：143/150/157°C；OTPW 预警告 120/143°C，见 0x07 FACTORY_CONF）、电荷泵欠压（UV_CP）、对 VS 短路（S2VS）、对地短路（S2G）、开路负载（OLA/OLB）。DRV_STATUS(0x6F) 可读详细状态。

### 3.8 DIAG / INDEX 输出

- **DIAG(11)**：高电平表示驱动故障（OT/UV/S2VS/S2G），或启用 StallGuard 后检测到堵转；ENN 拉高清除锁存错误。可作为 MCU 外部中断输入做紧急停机。
- **INDEX(12)**：每个电角度周期（4 个全步）输出一个脉冲，对应微步序列 0 位置，用于精确回零定位。

### 4.2 STEP 脉冲生成（TIM2 硬件 PWM，核心）

- TIM2 时钟 = 72MHz（APB1=36MHz，定时器 ×2）。CubeMX 已配置：PSC=0、ARR=8999、CCR2=4500（50% 占空比）。
- **STEP 频率 = 72MHz / (PSC+1) / (ARR+1) = 8kHz**。每个 PWM 周期输出一个 STEP 脉冲。
- 调速原理：**运行时改写 TIM2 的 ARR（自动重载值）即可改变 STEP 频率**（PSC 固定），频率为纯硬件产生、零抖动，满足 MicroPlyer 插值要求。

```c
// 例：设 STEP 频率 4kHz（ARR 采用预装载，HAL 会自动处理影子寄存器）
__HAL_TIM_SET_AUTORELOAD(&htim2, 72000000u / 4000u - 1u);
__HAL_TIM_SET_COMPARE(&htim2, TIM_CHANNEL_2, 72000000u / 4000u / 2u); // 保持50%占空比
```

- 50% 占空比的目的：STEP 高/低电平各 ≥100ns（数据手册），8kHz 下完全满足；且防止占空比过小导致高电平时间不足。

**默认配置下的速度换算**（电机步距角 1.8°，200 全步/转）：

| 微步设置 | STEP 频率 | 全步速率 | 转速 |
|---|---|---|---|
| 1/8（默认，MS1=MS2=0） | 8kHz | 1000 全步/s | **300 RPM** |
| 1/16 | 8kHz | 500 全步/s | 150 RPM |
| 1/32 | 8kHz | 250 全步/s | 75 RPM |
| 1/64 | 8kHz | 125 全步/s | 37.5 RPM |

> 一般公式：`RPM = fSTEP / (微步数 × 200) × 60`（1.8° 电机）。注意 **MicroPlyer 内部会把每个 STEP 插值成 256 细分**，所以机械分辨率始终可达 1/256 全步，微步设置决定的是"每个 STEP 脉冲推进几格正弦表"。

### 4.3 方向 / 使能 / 微步控制（GPIO）

| 信号 | 引脚 | 控制要点 |
|---|---|---|
| DIR | PA2 | 提前于 STEP 改变并保持 ≥20ns（数据手册 tDSU）。通常"方向切换→延时 100µs→再发 STEP"更稳妥 |
| ENN | PA0 | 低=使能功率级，高=关闭（线圈悬空自由滑行）。**上电默认高，需用户代码拉低** |
| MS1/MS2 | PA3/PA4 | 运行时切换微步（见 3.4 表）；TMC2209 序列器支持任意时刻无缝切换分辨率 |
| DIAG(可选) | PB0 等 | 配置为输入+EXTI 上升沿中断 → 紧急停机 |

### 4.4 速度控制与加减速（梯形/S 曲线）

- 电机由静止直接以高速启动会失步（尤其超过电机自启动频率）。需按 **梯形/S 形加减速** 调速。
- 推荐"双定时器"架构：
  1. **TIM2**：STEP 脉冲发生器（PWM 输出），通过改写 ARR 调速。
  2. **TIM3**：加减速节拍定时器（CubeMX 已使能更新中断），每个节拍（如 1ms）调用一次加减速函数，把当前频率换算为 ARR 写入 TIM2。
- 加减速参数：最大 STEP 频率 fmax、加减速斜率 a（step/s²）、目标步数 N。梯形规划：

```
加速段步数  N_acc = fmax² / (2a)
减速段步数  N_dec = fmax² / (2a)   (对称)
减速起始点  N - N_dec
```

- 建议在用户代码中维护：当前频率、目标频率、剩余步数、运行状态机（IDLE / ACCEL / CONST / DECEL / DONE）。

### 4.5 步数计数与到位判断

- **方案 A（简单，推荐先实现）**：TIM2 更新中断中 `step_count--`，减到 0 即"到位"（停止 PWM）。8kHz 中断频率对 Cortex-M3 压力不大，回调内只做加减法。
- **方案 B（硬件，零 CPU 开销）**：TIM2 已在 CubeMX 中配置 `MasterOutputTrigger=TIM_TRGO_UPDATE`、`MasterSlaveMode=ENABLE`，**将 TIM3 改为外部时钟模式（ITR0 = TIM2 的 TRGO）**，TIM3 即成为硬件步数计数器：TIM2 每产生一个 STEP 脉冲，TIM3 自动 +1，达到目标值触发中断停止 TIM2。此方案把 TIM3 的角色从"内部时基"改为"外部步计数"，只需在用户代码中重新配置 TIM3 的 SMCR 等寄存器（不改 CubeMX 文件）。

### 4.6 回零 / 堵转检测（可选扩展）

- **精确回零**：接 INDEX(12) 到 MCU（上升沿中断），在接近限位开关后以极低速（1/8 微步、几百 Hz STEP）找 INDEX 脉冲，实现亚全步级定位（INDEX 对应微步序列 0 位置）。
- **无传感器回零（StallGuard4）**：依赖 UART 寄存器（SGTHRS/TCOOLTHRS）配置，**本方案暂不使用，仅存档备查**。原理：电机顶到机械挡块 → SG_RESULT 低于 2×SGTHRS → DIAG 拉高 → MCU 外部中断停机。调参流程（数据手册 11.2）：
  1. 在正常工作速度下运行，监控 SG_RESULT；
  2. 缓慢加机械负载，记录堵转前 SG_RESULT 最低值，SGTHRS 取其一半；
  3. 运行并验证 DIAG 脉冲在堵转瞬间出现，微调 SGTHRS 至可靠。

### 4.7 控制流程图（推荐）

```
上电
 ├─ SystemClock_Config (CubeMX)
 ├─ MX_GPIO_Init / MX_DMA_Init / MX_TIM2_Init / MX_TIM3_Init / MX_USART1_UART_Init
 ├─ [USER] 确认电流已硬件设定：RSENSE 选型 + VREF(开路=满量程/分压)
 │     微步由 MS1/MS2(GPIO) 决定；PDN_UART 已接 GND → 静止自动降流

 ├─ [USER] ENN=0  → 电机使能（功率级开）
 └─ 主循环等待运动指令
       │
       ▼
   收到运动指令(方向 + 速度 + 步数)
    ├─ 设置 DIR、MS1/MS2
    ├─ 启动 TIM3 加减速节拍 + HAL_TIM_PWM_Start(TIM2)
    ├─ 中断驱动：
    │    TIM3 更新中断 → 梯形加减速 → 改写 TIM2 ARR

    ├─ 步数到达 → HAL_TIM_PWM_Stop(TIM2)
    └─ 可选：ENN=1 释放电机，或保持使能以维持保持力矩
```

### 6.3 关键实现要点

1. **缓升启动**（✅ 已实现）：`Motor_Start(hz)` → 换算目标 ARR（**计入 TIM2 PSC=99**：`ARR = 72MHz/((99+1)×f) - 1 = 72M/(100×f) - 1`）；TIM3（≈1ms 节拍）中断内把 current_arr 以 `ARR_STEP=100` 步长向 target_arr 逼近；**运行中缓升不置 UG**（由自然溢出加载影子 ARR，避免打断 PWM 相位），同步写 CCR=ARR>>1（50% 占空比）。
2. **缓降停止**（✅ 已实现）：`Motor_Stop()` → target_arr 置为起始低速（20Hz），缓降到位后 `HAL_TIM_PWM_Stop`（HAL 维护通道状态，便于下次重启）；**到达目标（含停机）即 `HAL_TIM_Base_Stop_IT(&htim3)` 省 CPU**，下次 `Motor_Start/Stop` 重新启动节拍。
3. **状态监控**（✅ 已实现）：`Motor_GetSpeedHz()` 返回当前频率、`Motor_IsRunning()` 返回运行状态。
4. **步数计数**（后续）：TIM2 更新中断 `remain_steps--`，归零即 DONE。回调要短，只做整数运算。
5. **电流设定（硬件，无需代码）**：确认 RSENSE 按电机额定电流选择（见 3.5 表）；VREF 开路 = 满量程；若需降流，VREF 接分压器（如两个 10kΩ 分压 → 1.25V ≈ 50% 电流）。PDN_UART 已接 GND，静止自动降流无需软件参与。
6. **USART1（可选）**：仅作调试串口使用（printf 输出状态、接收简单指令），**不要与 PDN_UART 相连**。
7. **运动状态机**放主循环轮询或中断回调，注意 `volatile` 修饰跨中断共享变量。

## 八、调试与验证建议

1. **先转起来**：✅ **已实现** —— `Motor_Init()` 设置方向/微步/使能后直接启动到 `MOTOR_MAX_HZ_DEFAULT`（800Hz ≈ 30RPM）。示波器测 PA1 应立即看到 800Hz/50% 方波。
2. **用示波器查波形**：PA1 应为 **800Hz/50%** 方波（周期 1.25ms）；PA0=低；调 `Motor_Start(hz)` 或改 `MOTOR_MAX_HZ_DEFAULT` 可验证不同频率。若电机不转，先量 ENN/STEP/DIR 电平与 VS 电压、检查电荷泵电容。
3. **PDN_UART 接地检查**：用万用表确认 PDN_UART=0V；电机静止时电流自动降到出厂默认 IHOLD（可用电流探头对比运行/静止电流）。若 PDN_UART 悬空或接错，静止降流不生效。
4. **电流实测**：钳形/探头测一相电流，与公式核对，调整 VREF 分压（或更换 RSENSE）；手感电机温度，>70°C 需降流或加强散热。
5. **加减速整定**：从低速小步数开始（如 100 步、500Hz），逐步提高 fmax 与加速度，观察是否失步（DIAG/噪声/到位误差）。
6. **堵转回零验证**（可选）：开 StallGuard 后让电机顶限位，确认 DIAG 中断触发且电机及时停止、无撞击异响。
7. **电磁/干扰**：电机线双绞、远离信号线；MCU 与驱动共地；必要时按数据手册加 470pF 输出滤波。
